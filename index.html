How alerts work

Set a target price for each game. When you update its current price below that target, the app flags the deal and can send a browser notification if notifications are supported and permission is granted.

Automatic background alerts require a reliable price-data source and a hosted backend or scheduled service. This local prototype cannot independently monitor the PS Store while closed.
